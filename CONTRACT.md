#1.Communication Plan

To ensure smooth collaboration, the team will maintain consistent communication and transparency throughout the project.

- Missed meetings must be communicated 24 hours in advance.
- Trello cards must reflect accurate progress (To Do / In Progress / Done).

#2. Git Workflow

The team will use GitHub for version control and collaboration under the lgu-it organization.

- At least **one peer review** is required before merging.
- No direct commits to `main` are allowed.

#3.  Code Review Standards

The team will follow these standards to ensure quality, maintainability, and professionalism.

| Documentation          | Functions and classes must include brief descriptions 
| Testing                | Each new feature should include or update corresponding test cases 


#Process:
1. Each Pull Request must be reviewed by at least one other member.
2. Reviewers will leave constructive feedback in GitHub comments.
3. Changes must be approved before merging.
4. All team members share equal responsibility for maintaining high-quality code.


#4. Conflict Resolution Process

Conflicts may arise regarding to code decisions, task assignments, or schedules. The team will follow this fair, structured resolution process:


- Focus on solving the issue, not assigning blame.
- Document all major decisions on Trello for transparency.


#5. Collaboration & Accountability

  - All tasks will be created and tracked on Trello, categorized as *To Do*, *In Progress*, or *Done*.
  - Each member must:

                   - Participate in at least one code review per week.
                   - Deadlines will be reviewed every Friday during the team meeting.

#6.  Agreement

By signing this contract, each member agrees to:
- Contribute equally and meet assigned deadlines.
- Maintain open communication and professionalism.
- Follow the Git workflow and code review standards.
- Respect the conflict resolution process.
